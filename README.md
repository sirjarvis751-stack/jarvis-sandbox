# jarvis-sandbox

Jarvis's scratchpad — experiments, skill tests, side-project stubs for Sir Hamdan Al Mansoori.

## Purpose

This repository exists as a proving ground for OpenClaw's `gh-issues` automation and
as a staging area for small experiments before they migrate to their own repos.

Typical inhabitants:

- A trivial "hello" script used to exercise the toolchain
- Issue templates that Jarvis's sub-agents can practise on
- Throwaway scripts, notes, and one-off integrations

## Files

- `hello.py` — greets the world; see `python3 hello.py`

## Conventions

- Experiments live at the root. Once something proves itself, it graduates into its own repo.
- Open issues here to test Jarvis's `gh-issues` flow end-to-end.
